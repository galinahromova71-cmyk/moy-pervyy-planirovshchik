# Мой первый планировщик

Личный планировщик контента для Telegram. Работает на HTML, CSS и JavaScript, хранит записи в браузере через localStorage.

## Возможности

- Идеи без даты, план по дням, месячный календарь и доска статусов.
- Черновики, заметки и ссылки на материалы.
- Поиск, фильтры и подсказки о сроках.
- Архив, восстановление и подтверждение удаления.
- JSON-копии, проверяемый импорт и отмена последнего импорта.

## Запуск

Откройте опубликованную страницу GitHub Pages либо `index.html` локально. Установка библиотек и серверная база данных не нужны. Для постоянной работы используйте один и тот же адрес страницы.

Записи не синхронизируются между браузерами и устройствами. Скачивайте JSON-копии отдельно от браузера; при очистке браузерного хранилища записи могут исчезнуть. Для ручного переноса плана на другое устройство используйте экспорт и импорт.

В репозитории находятся исходный код, документация и резервные копии файлов проекта. Записи, введённые в браузере, сюда автоматически не загружаются.
